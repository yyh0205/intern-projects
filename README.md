# intern-projects

实习期间开发的个人项目集合。

## 项目列表

### 1. 史海长卷 · 华夏历史 3D 百科
- 路径：[app1/](app1/)
- 一个基于 Web 3D 技术的中国历史交互式百科应用。

### 2. 雪梨英语游乐场 · WORD PLAY
- 路径：[app2/](app2/)
- 一个英语词汇学习互动应用。

### 3. 扫码签到抽奖工具
- 路径：[app3/](app3/)
- 一个 Node.js 应用，支持生成签到二维码、扫码签到、后台开奖、名单导入导出等功能，适用于培训活动现场。

### 4. 脉脉自动打招呼脚本
- 路径：[app4/](app4/)
- 一个 Tampermonkey 油猴脚本，在脉脉人才库页面自动点击「立即沟通」并发送预设话术，提升招聘效率。

### 5. OpenClaw 课程笔记
- 路径：[app5/](app5/)
- AI Agent 配置教程笔记，涵盖 SOUL.md / USER.md 的编写方法、工作区组织和 Skill 创建实战。

## 技术栈

- app1、app2：独立单页 HTML 应用，原生 HTML/CSS/JavaScript
- app3：Node.js 18+ 服务端应用（需 `npm install && npm start` 运行）
- app4：Tampermonkey 用户脚本（JavaScript）
- app5：Markdown 文档笔记
