# 脉脉自动打招呼 SOP

在脉脉人才库页面自动点击「立即沟通」并发送预设话术，替代手动逐个打招呼。

## 前置准备

- 脉脉企业版账号（HR 招聘权限），已开通 VIP
- Chrome 浏览器，已登录 maimai.cn
- 安装 Tampermonkey 扩展（需购买，App Store 搜索）

## 安装步骤

1. Chrome 安装 Tampermonkey 扩展，并开启「访问所有网站」权限
2. 打开 `maimai.cn`，进入 人才银行 → 招人 → 搜索 页面
3. 点击 Tampermonkey 图标 → 新建脚本
4. 把 `maimai-auto-greet.user.js` 的全部内容粘贴进去，Ctrl+S 保存
5. 刷新脉脉页面，右下角会出现红色「🚀 一键沟通」按钮

## 使用方法

1. 先滚动页面把所有候选人加载出来
2. 等 2 秒让页面完全加载
3. 点击「🚀 一键沟通」，脚本会自动逐个点击并发送话术
4. 停止：刷新页面即可

## 修改话术

打开脚本文件，修改 `TALK_TEXT` 那一行的引号内容即可。

## 注意事项

- 一次建议不超过 40-50 人，太多可能触发脉脉风控
- 运行中不要切换标签页或最小化窗口
- 如果弹出验证码或异常提示，立即刷新页面停止
- 脉脉 VIP 道具用完后脚本会中断
