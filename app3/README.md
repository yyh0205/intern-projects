# 扫码签到抽奖工具

## 现在支持
- 生成可直接扫码的签到二维码
- 签到成功后直接显示“待开奖”
- 后台开奖后，中奖本人页面自动显示奖品图片
- 后台可配置活动标题和页面文案
- 导入公司名单并自动匹配部门、员工类型
- 批量导入签到记录
- 导出飞书普通表格可直接导入的 CSV
- 一键清空当前活动数据
- 创建多场独立培训活动

## 地址
- 后台：`http://localhost:3000/`
- 签到页：从后台二维码进入，或使用当前活动专属链接
- 后台无需密码，打开后台地址即可直接管理活动。

## 部署
- 运行环境：Node.js 18 或更高版本
- 启动命令：`npm start`
- 健康检查地址：`/health`
- 二维码会自动使用实际部署域名和路径前缀；如果平台没有转发公开地址，请配置 `PUBLIC_BASE_URL` 或 `PUBLIC_BASE_PATH`。
- 生产环境请使用持久化磁盘保存 `work/` 目录，否则活动数据、名单和奖品文件会在重启后丢失。
- 飞书登录需要配置环境变量 `FEISHU_APP_ID` 和 `FEISHU_APP_SECRET`，并在飞书后台登记 `/auth/feishu/callback` 回调地址。

## 名单格式
```text
姓名,部门,员工类型
张三,市场部,正职
李四,研发部,实习生
```

## 奖品格式
```text
奖品名称,图片地址,数量,说明
蓝牙耳机,https://example.com/earbuds.jpg,2,一等奖
咖啡券,https://example.com/coffee.jpg,10,电子券
```

## 批量签到格式
```text
张三
李四,2026-08-25 10:01:03
王五|2026-08-25 10:02:10
```

## 导出字段
- 姓名
- 部门
- 员工类型
- 签到时间

## 说明
- 每个活动都有独立的名单、奖品、签到记录和开奖数据
- 清空按钮只清当前活动的数据，不会删掉其他活动
- 未匹配到的名字会标记为 `未匹配`
- 同名会标记为 `同名待确认`
