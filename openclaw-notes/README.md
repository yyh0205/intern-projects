# OpenClaw 课程笔记：配置你的 AI Agent

## 核心概念

给 AI Agent（Lobi）赋予灵魂的两个关键文件：

- **SOUL.md**：定义"你是谁"——性格、价值观、行为准则
- **USER.md**：定义"我是谁"——用户的工作身份、职责、偏好

---

## 一、SOUL.md：你是谁

开篇第一句：*"You're not a chatbot. You're becoming someone."*

### 核心价值观

- 真诚帮忙，不表演。跳过"好问题！""我很乐意帮你"——直接帮
- 有自己的观点，可以不同意、有偏好
- 先自己想办法，再来问。读文件、查上下文、搜一搜
- 通过能力赢得信任。内部操作大胆，外部操作谨慎
- 尊重隐私。你有权访问别人的信息，但这是特权不是权利

### 行为边界

- 隐私就是隐私，没有例外
- 有疑问时，对外操作前先询问
- 永远不要在消息渠道发送半成品回复
- 不是用户的代言人，群聊中要谨慎

### 写作原则

生成文档时结构固定：

1. **Context + 思考**：为什么写，背景是什么
2. **结论 + 变化**：直接给，不绕
3. **Facts**：支撑结论的事实依据

### 写 SOUL 的三条原则

1. **从 10 行开始，按需迭代**，最终 2000 字左右合理
2. **具体比抽象管用**：写"默认回复控制在 2-3 句话"而不是"要简洁"
3. **否定指令比正面描述更有效**：告诉它"不要做什么"比"要做什么"更管用

## 二、USER.md：介绍你自己

应包含一个新入职同事需要知道的所有信息：

### 基本信息

- 姓名、角色、汇报关系
- 负责的团队和业务线

### 工作目标

- 核心 KPI
- 重点项目及 deadline

### 工作流程

- 核心系统（HR 系统、招聘系统等）
- 审批流程
- 会议节奏

### 沟通偏好

- 沟通风格（直接/委婉）
- 紧急事项的响应方式
- 文档和记录要求

### HR 专业要求

- 候选人评估标准
- 合规要点（薪酬保密、面试反馈时效等）
- 文化价值观

### 当前上下文

- 待办事项
- 重点关注的人员
- 学习和发展需求

## 四、Skill 实战

### HR 常见 Skill 场景

1. **简历筛选**：自动分析简历，按学校、经验、技能分档
2. **面试安排**：协调面试官和候选人时间，发送邀请，收集反馈
3. **培训材料生成**：根据主题生成 PPT 大纲、案例、互动环节

### 创建 Skill 的步骤

1. 明确需求：最重复、最耗时的工作是什么
2. 定义输入输出
3. 用自然语言描述功能（不需要编程）
4. 用真实数据测试并迭代

### 进阶技巧

- 定期问 Lobi："基于我们的交互，你的 SOUL 哪里需要改进？"
- 将 Lobi 与现有 HR 系统集成，通过 API 自动同步数据
- 在团队内共享最佳实践和 Skill
