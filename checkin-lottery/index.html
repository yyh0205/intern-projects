扫码签到抽奖工具

一个培训活动现场使用的签到抽奖系统，支持生成签到二维码、扫码签到、后台开奖、名单导入导出等功能。

功能

  • 生成可直接扫码的签到二维码
  • 签到成功后显示"待开奖"，后台开奖后中奖人页面自动显示奖品
  • 后台可配置活动标题和页面文案
  • 导入公司名单并自动匹配部门、员工类型
  • 批量导入签到记录，导出 CSV
  • 支持多场独立培训活动，互不影响

运行方式

需 Node.js 18+ 环境，执行 npm install && npm start 启动，访问 http://localhost:3000。
